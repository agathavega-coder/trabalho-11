Boas Práticas de Programação

Escreva códigos mais claros, organizados e fáceis de manter.

O que são boas práticas de programação?

Boas práticas de programação são hábitos e técnicas que ajudam a desenvolver códigos de qualidade. Elas tornam os programas mais fáceis de entender, corrigir, atualizar e compartilhar com outras pessoas. Aplicar essas práticas contribui para projetos mais organizados, eficientes e confiáveis.

As 5 características principais

01

Legibilidade

Escrever códigos fáceis de ler e compreender, utilizando nomes descritivos para variáveis, funções e classes.

Exemplo: calcularTotal() em vez de ct().

02

Organização

Separar o código em partes bem definidas, manter os arquivos organizados e utilizar indentação adequada.

Exemplo: separar HTML e CSS em arquivos.

03

Consistência

Seguir os mesmos padrões de nomenclatura, formatação e escrita em todo o projeto, facilitando a leitura do código.

Exemplo: manter um padrão para nomes de classes.

04

Manutenibilidade

Desenvolver códigos que possam ser corrigidos, modificados e ampliados com facilidade, sem causar problemas desnecessários.

Exemplo: criar funções pequenas e reutilizáveis.

05

Colaboração

Escrever código compreensível para outras pessoas, documentar decisões importantes e compartilhar alterações de forma organizada.

Exemplo: utilizar Git e GitHub para trabalhar em equipe.

Programar bem vai além de fazer funcionar!

Um bom código também precisa ser compreensível, organizado e preparado para evoluir.
